# apps/

User‑facing Sextant applications. Each app is a pnpm workspace package scoped
under `@sextant/*` and built/served via Turborepo.

Planned:

- **`web/`** — the trader dashboard (positioning maps, levels, journal, copilot).
- **`marketing/`** — the public site (sextant.ai).

> Add a new app by creating a folder here with its own `package.json`.
